# Land Condition Monitor

An automated regional decision-support platform designed to ingest, process, and analyze meteorological and soil time-series data for agricultural planning.

---

## Overview

The Land Condition Monitor bridges raw weather data and practical farm management. 
This system runs automated ETL pipelines to evaluate critical agricultural thresholds such as tracking soil temperature moving averages and cumulative rainfall. 
The dashboard will show optimal windows for livestock turnout and crop sowing.
